# Getting Started

## Prerequisites

- Node.js (compatible with your local Next.js version)
- npm (or yarn/pnpm/bun)

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Where to start in the code

- `app/page.tsx`: home
- `app/dashboard/page.tsx`: dashboard shell (sidebar + content)
- `components/app-sidebar.tsx`: navigation sidebar
- `components/ui/*`: reusable UI primitives
