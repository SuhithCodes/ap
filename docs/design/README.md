# Design / UX

## Hybrid default layout

- Left: Chat (intent + narrative + suggestions)
- Right: Visuals (charts + evidence + interaction)

## Interaction principles

- **Evidence first**: insights should correspond to what’s visible in the chart.
- **No re-asking**: conversational memory + UI context events prevent repeated filters.
- **Explain chart changes**: when switching chart types, say why.
- **State preservation**: switching between “Focus on Chat” and “Show Visuals” must not reset analysis state.
